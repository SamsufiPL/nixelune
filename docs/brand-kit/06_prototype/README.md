# Lokalny prototyp NIXELUNE

Otwórz plik `index.html` w aktualnej przeglądarce desktop lub mobile. Połączenie z internetem nie jest potrzebne. Nie wymaga instalacji Node.js, serwera ani żadnych bibliotek.

**Co działa:** opadające grupy 3–4 heksów, obrót o 60°, ruch, szybki zrzut, przechowywanie elementu, ghost projection, wyszukiwanie grup 5+ jednego koloru, usuwanie połączeń, grawitacja, wynik, cel etapu, pauza, restart i game over. Sterowanie klawiaturą i dotykowe.

**Czego jeszcze nie ma:** dopracowanej krzywej trudności, zapisu progresu, leaderboardów, efektów dźwiękowych, logowania, sieciowych wyzwań i finalnej optymalizacji do sklepów z aplikacjami.

Prototyp nie jest produkcyjną implementacją, a punktem startowym do walidacji podstawowej idei gry. Wszystkie kolory są importowane z `../04_design_system/tokens.css`.
