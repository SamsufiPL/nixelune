# NIXELUNE — instrukcja dla gracza

## Cel

Układaj opadające mineralne elementy na planszy z sześciokątów. **Połącz minimum 5 sąsiadujących pól tego samego koloru**, aby uruchomić świetlną ścieżkę. Aktywowane pola znikają i zwalniają przestrzeń.

## Sterowanie

| Akcja | Komputer | Telefon (prototyp) |
|---|---|---|
| Przesuń | Strzałki lewo/prawo lub A/D | Przyciski ◀ i ▶; na planszy przesuń palcem |
| Obróć o 60° | Strzałka w górę lub W | Obróć / stuknij planszę |
| Upuść | Spacja lub strzałka w dół | Duży przycisk Upuść |
| Zamień | C | Zamień |
| Pauza | P lub Esc | Pauza |
| Restart | R | Nowa gra |

Gra kończy się, gdy nie można umieścić nowego elementu. Wynik rośnie po każdej aktywowanej ścieżce, a aktywacje kaskadowe budują łańcuch.

**Uwaga:** demonstrator jest prototypem; animacje i balans zostaną dostosowane w produkcji.
