# Generator grafik wektorowych

`assets_source.py` jest kodem źródłowym makiet SVG/PNG, kolorystyki i znaków podstawowych. Może odtworzyć ich bazowe warianty po `pip install cairosvg` i uruchomieniu `python assets_source.py`. **Uwaga: nadpisuje bazowe pliki.** Warianty transparentne powstały jako eksporty z głównego źródła; jeśli zmieniasz geometrię logo, przegeneruj również je.

Pliki SVG są już edytowalne bez uruchamiania skryptu.
